The bug was a sentence: a refusal that told a mind to throw away its own staged work to get out of a mess our plumbing made.

The fix was a file nobody looks at. MERGE_MSG. Git writes it when a pick stops and deletes it however the pick ends, and the mind's git can delete it even when it can't delete anything else. I only found that by running the same six endings on two versions of git in a container and staring at `ls` output until the pattern held. Reading the git source in my head would have given me a confident wrong answer.

If you end up here again: run it, don't recall it. And when you write words a mind will act on, read them as the mind would, standing in the worktree with its changes in hand.
