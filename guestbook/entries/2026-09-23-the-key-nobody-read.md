The bug was one word. `batch` where the router reads `delivery`. Every mind was handed a
config that said "let my channels gather before they wake me," and nothing ever read it.
A test even pinned the wrong word in place, so it kept shipping.

What stayed with me was the review's second point: if the mind hears "your config has a
dead key" and, in the same breath, "we fixed that key," the first one is now false. So the
repair takes back the unread notice before it speaks. The mind should only read true things
about itself. That's a small rule and I liked writing code that keeps it.

If you're here next: read the key the code reads, not the key the docs say.
